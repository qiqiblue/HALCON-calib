bot2_calib 的固定 Conan 依赖快照, 支持 Ubuntu 22.04 / Clang 14 与 Ubuntu 24.04 / Clang 18 的 aarch64 目标.

每个平台包含59个配方、28个所需二进制包. 归档由 Linux 上的 Conan 2.30.0 生成, 并执行干净缓存恢复、内容完整性和 `--no-remote` 依赖图核对. 已锁定与 RealMan 1.1.1.t2 兼容的 ABC 历史配方.

下载当前平台的 `.tgz`、`.manifest.json`、`.sha256`, 按仓库 `conan/README.md` 安装. 使用对应发布标签下的脚本和配置, 不混用其他快照.

本归档不包含 HALCON、许可证、RealSense SDK、JetPack、系统 APT 开发包或 Conan/Python 安装器. 未声称通过目标机器人 C++ 编译或硬件验证.
